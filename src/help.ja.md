# mdfolio の使い方

mdfolio は、Markdown 文書をブラウザだけで読むためのビューアです。サーバーもインストールも要りません。文書はこの端末の中だけで処理され、外部には送信されません。

## 文書を開く

| やりたいこと | 操作 |
|---|---|
| フォルダごと開く | 「フォルダを開く」を押してフォルダを選ぶ。または、フォルダをこの画面にドロップする |
| ファイルだけ開く | 「ファイルを開く」を押す。または、`.md` ファイルをドロップする |
| 前回のフォルダを開く | 開始画面の「前回のフォルダを開く」を押す（Edge / Chrome のみ） |

フォルダを開くと、左にファイルの一覧、右にページ内の目次が表示されます。

> [!NOTE]
> フォルダを選ぶとき、ブラウザが「ファイルの表示を許可しますか」や「アップロードしますか」と確認することがあります。これはブラウザがこのページにフォルダの読み取りを許可するための確認です。ファイルが外部に送信されることはありません。

ファイルだけを開いた場合、同じフォルダにある画像は表示できません。画像も表示したいときは、フォルダごと開いてください。

## 読む

- **文書の切り替え**: 左の一覧、または本文中のリンクで移動します。ブラウザの「戻る」「進む」も使えます。
- **検索**: 上部の検索欄に語を入れます。`Ctrl+K`（Mac は `⌘K`）または `/` で検索欄に移動します。空白で区切ると、すべての語を含む文書に絞り込みます。大文字と小文字、全角と半角は区別しません。
- **テーマ**: 右上のボタンを押すたびに「自動 → ライト → ダーク」と切り替わります。
- **印刷・PDF 保存**: ブラウザの印刷機能を使います。本文だけが出力されます。
- **更新の反映**: Edge / Chrome でフォルダを開いている場合、表示中のファイルを編集して保存すると、表示が自動で更新されます。ファイルの追加や削除は、メニューの「再読み込み」で反映します。

## 配布する

メニューの「サイトとして書き出す」を使うと、開いている文書一式を 1 つの HTML ファイルにまとめられます。受け取った人は、その HTML ファイルを開くだけで読めます。

- 文書から参照されている画像や添付ファイルも一緒に入ります（1 件 20MB まで）。
- 数式や図を使っていない場合は、そのためのプログラムを省いてファイルを小さくします。
- メールやチャットで HTML を直接送ると、途中で内容が書き換えられて動かなくなることがあります。zip にまとめて送ると確実です。

## 見た目を変える

この HTML と同じフォルダに `mdfolio.css` を置くと、その CSS で見た目が変わります（開き直すと反映されます）。配色の変数（`--accent` など）を変えると、本文・画面・図の色がそろって変わります。

書き出したサイトに入れるには、「サイトとして書き出す」の画面で「CSS を選ぶ」から同じファイルを選びます。ブラウザーの決まりで、隣のファイルの中身を自動では読み取れないためです。

## サイドバーの並びを決める

フォルダの直下に `_sidebar.md`（または `SUMMARY.md`）を置くと、その内容がサイドバーの「ナビ」に表示されます。リンクのリストを書きます。

```markdown
- [はじめに](README.md)
- 使い方
  - [インストール](guide/install.md)
  - [設定](guide/config.md)
```

## 使える記法

見出し、リスト、表、コード、リンク、画像などの一般的な Markdown に加えて、次の記法が使えます。

| 記法 | 書き方 |
|---|---|
| タスクリスト | `- [ ] 未完了`、`- [x] 完了` |
| 脚注 | 本文に `[^1]`、別の行に `[^1]: 脚注の内容` |
| 補足・警告 | `> [!NOTE]`、`> [!TIP]`、`> [!IMPORTANT]`、`> [!WARNING]`、`> [!CAUTION]` |
| 数式 | 文中は `$E = mc^2$`、独立した式は `$$` で囲む |
| 図 | 言語名を `mermaid` にしたコードブロック |

リンクと画像は、文書からの相対パスで書きます（例: `[設定](guide/config.md)`、`![構成図](img/overview.png)`）。

図（Mermaid）は、フローチャート、シーケンス図、クラス図、状態遷移図、ER 図、ガントチャート、円グラフなどが使えます。**マインドマップ（`mindmap`）とアーキテクチャ図（`architecture-beta`）は使えません**（同梱している軽量版に含まれていないため）。書いた場合は、図の代わりにエラーを表示します。

## 外部の画像

インターネット上の画像や動画（`https://…`）は、初期設定では表示しません。読み込むと、配信元のサーバーに「この文書を開いた」ことが伝わるためです。図（Mermaid）の中で指定された画像も同じ扱いで、ブラウザーの機能（コンテンツセキュリティポリシー）でも読み込みを止めています。

メニューの「外部の画像を表示する」で切り替えられます。表示する側に切り替えると、ページが自動で再読み込みされます。フォルダを開いていた場合は、再読み込みのあとで開き直してください。

## キーボードで操作する

| キー | 動作 |
|---|---|
| `Ctrl+K`（Mac は `⌘K`）、`/` | 検索欄へ移動 |
| `↑` `↓` `Enter` | 検索結果を選んで開く |
| `Tab` | 次の項目へ移動。ページの先頭で押すと「本文へ移動」が出る |
| メニュー（⋯）で `Enter` または `↓` | メニューを開く。`↑` `↓` で項目を選ぶ |
| `Esc` | 検索結果・メニュー・ダイアログを閉じる |
| 横に長い表やコードで `←` `→` | Tab でその表やコードへ移動してから、横にスクロール |

## 困ったとき

| 状況 | 対処 |
|---|---|
| 画像が表示されない | ファイルだけを開いている場合は、フォルダごと開く。画像のパスが、文書からの相対パスになっているか確認する |
| 文字化けする | 文書を UTF-8 で保存し直す（対応: UTF-8、BOM 付き UTF-16、Shift_JIS） |
| リンク先が「見つかりません」になる | リンクのパスとファイル名を確認する。`C:\…` のような絶対パスは使えない |
| 「前回のフォルダを開く」が出ない | Edge / Chrome 以外では使えない。フォルダを選び直す |
| 数式や図が表示されない | 書き出した HTML で、書き出し時に数式や図を使っていなかった場合は表示できない。元のフォルダから書き出し直す |
