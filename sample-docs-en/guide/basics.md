# Basics

## Open documents

On the start screen, press "Open folder" and choose the folder that contains your documents. You can also drop the folder onto the window.

> [!TIP]
> In Edge or Chrome, you can press "Reopen last folder" on the start screen next time to open the same folder again.

## Move between documents

- Choose a document in the sidebar on the left
- Follow links in the text (for example, [Markdown syntax](markdown-syntax.md) or [the list of settings](../reference/settings.md#list-of-settings))
- Jump to a heading with "On this page" on the right
- Use the browser's Back and Forward buttons

## Search

Type words in the search box at the top. `Ctrl+K` or `/` moves to the search box.

| Type | Finds |
|---|---|
| `export` | Documents that contain "export" |
| `export attachment` | Documents that contain both words |
| `MARKDOWN` | Matches regardless of upper or lower case |

When you choose a result, the matching words in the text are highlighted.

## Change the view

The button at the top right switches the theme (auto, light, dark). The menu (⋯) lets you switch the language, show external images, and reload.

## Print

Use the browser's print function (`Ctrl+P`). The sidebar and the outline are left out, and only the document body is printed. Choose "Save as PDF" to make a PDF.
