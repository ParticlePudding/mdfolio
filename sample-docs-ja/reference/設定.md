# 設定

## 設定の一覧

`mdfolio.html` の中にある `mdv-config` という設定ブロックを書き換えると、既定の動作を変えられます。

```html
<script type="application/json" id="mdv-config">{"title":"","lang":"auto","theme":"auto","home":"","allowExternalImages":false,"allowDownloads":true,"lockExternalImages":false,"hosted":false}</script>
```

| キー | 値 | 意味 |
|---|---|---|
| `title` | 文字列 | サイトのタイトル。空ならフォルダ名を使う |
| `lang` | `auto` / `ja` / `en` | 画面の言語 |
| `theme` | `auto` / `light` / `dark` | 最初に表示するテーマ。`auto` は OS の設定に合わせる |
| `home` | 文書のパス | 最初に表示する文書。空なら `README.md` |
| `allowExternalImages` | `true` / `false` | 外部の画像を最初から表示するか |
| `allowDownloads` | `true` / `false` | `false` にすると、ファイルの保存を伴う操作（サイトとして書き出す、添付ファイルの保存）を出さない |
| `lockExternalImages` | `true` / `false` | `true` にすると、外部の画像を常に読み込まない。利用者は切り替えられない |
| `hosted` | `true` / `false` | `true` にすると、動作確認用の公開ページであることを開始画面と使い方に表示する |

下の 3 つは、ファイルの保存や外部の読み込みができない場所（別のページの中に埋め込んで表示する環境など）に置くための設定です。手元で開く場合は、既定のままで使います。

> [!WARNING]
> HTML の中で書き換えてよいのは、この設定ブロックだけです。プログラムの部分を書き換えると、安全のための仕組み（CSP）によって動かなくなります。見た目は、HTML を書き換えず、隣に置く `mdfolio.css` で変えます。

## 利用者ごとの設定

テーマ・言語・外部の画像・サイドバーの開閉は、利用者が画面で変更するとブラウザに保存され、設定ブロックより優先されます。

## 最初に表示する文書

次の順で決まります。

1. 設定の `home`
2. フォルダ直下の `README.md`
3. フォルダ直下の `index.md`
4. 一覧の先頭の文書
