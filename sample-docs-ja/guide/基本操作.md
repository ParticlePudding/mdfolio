# 基本操作

## 文書を開く

開始画面で「フォルダを開く」を押し、文書の入ったフォルダを選びます。フォルダをウィンドウにドロップしても開けます。

> [!TIP]
> Edge または Chrome では、次回から開始画面の「前回のフォルダを開く」で同じフォルダをすぐに開けます。

## 文書を移動する

- 左のサイドバーから選ぶ
- 本文中のリンクをたどる（例: [Markdown 記法](Markdown記法.md)、[設定の一覧](../reference/設定.md#設定の一覧)）
- 右の「このページの目次」から見出しへ移動する
- ブラウザの「戻る」「進む」を使う

## 検索する

上部の検索欄に語を入力します。`Ctrl+K` または `/` で検索欄に移動できます。

| 入力 | 結果 |
|---|---|
| `書き出し` | 「書き出し」を含む文書 |
| `書き出し 添付` | 両方の語を含む文書 |
| `ＭＡＲＫＤＯＷＮ` | 全角・半角、大文字・小文字を区別せずに一致 |

結果を選ぶと、本文中の一致した語に印が付きます。

## 表示を変える

右上のボタンでテーマ（自動・ライト・ダーク）を切り替えます。メニュー（⋯）からは、言語の切り替え、外部の画像の表示、再読み込みができます。

## 印刷する

ブラウザの印刷機能（`Ctrl+P`）を使います。サイドバーや目次は出力されず、本文だけが印刷されます。「PDF として保存」を選べば PDF にできます。
