# 制限事項

## ブラウザ

| ブラウザ | 対応 |
|---|---|
| Edge / Chrome | すべての機能 |
| Firefox / Safari | 閲覧・検索・書き出し。「前回のフォルダを開く」と自動更新は使えない |

## 文書

- 1 つのフォルダで読み込める文書は 5,000 件までです。
- 10MB を超える文書は、変換せずにテキストとして表示します。
- 名前が `.` で始まるフォルダとファイル、`node_modules` フォルダは読み込みません。
- 文字コードは UTF-8、BOM 付き UTF-16、Shift_JIS に対応します。

## リンクと画像

- リンクと画像は、文書からの相対パスで書きます。`C:\docs\a.md` のような絶対パスは使えません。
- ファイルだけを開いた場合（フォルダを開いていない場合）、画像は表示できません。
- インターネット上の画像は、初期設定では表示しません[^ext]。

[^ext]: メニューの「外部の画像を表示する」で切り替えられます。表示する側に切り替えるときは、ページを再読み込みします。

## 図

Mermaid の Mindmap と Architecture の図には対応していません。
