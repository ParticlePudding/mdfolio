# 配布方法

文書を他の人に渡す方法は 2 つあります。

## 1. サイトとして書き出す

メニューの「サイトとして書き出す」を選ぶと、開いている文書がすべて入った HTML ファイルが 1 つできます。

1. サイトのタイトルと、最初に表示する文書を選ぶ
2. 「書き出す」を押す
3. できた HTML ファイルを渡す

受け取った人は、その HTML ファイルをダブルクリックするだけで読めます。フォルダを選ぶ操作は要りません。

> [!IMPORTANT]
> 書き出した HTML には、文書の内容がそのまま入ります。渡してよい内容かどうかを確認してから配布してください。

文書から参照されている画像と添付ファイル（1 件 20MB まで）も一緒に入ります。どの文書からも参照されていないファイルは入りません。

## 2. ビューアと文書フォルダを一緒に渡す

`mdfolio.html` と文書のフォルダを zip にまとめて渡します。受け取った人は `mdfolio.html` を開き、文書のフォルダを選びます。文書を更新しながら使う場合はこちらが向いています。

## どちらを選ぶか

| | サイトとして書き出す | ビューアとフォルダを渡す |
|---|---|---|
| 受け取った人の操作 | 開くだけ | フォルダを選ぶ |
| 文書の更新 | 書き出し直す | ファイルを差し替える |
| 向いている場面 | 完成した文書の配布 | 作成中の文書の共有 |

## 見た目を変える

HTML と同じフォルダに `mdfolio.css` を置くと、その CSS で見た目が変わります。書き出すときに入れるには、書き出しの画面の「CSS を選ぶ」で同じファイルを選びます。
