# mdfolio sample documents

These documents show what mdfolio can do. Choose a document from the list on the left (on a narrow screen, open the list using the ≡ button at the top left), or follow the links below.

- [Basics](guide/basics.md): open, read and search
- [Markdown syntax](guide/markdown-syntax.md): everything mdfolio can display
- [Distributing documents](guide/distributing.md): share documents as one HTML file
- [Settings](reference/settings.md) and [Limitations](reference/limitations.md)

![The flow from opening a folder to reading and exporting it](images/overview.svg)

## What you can try here

| Try this | Where |
|---|---|
| Links between documents, and Back / Forward | The links on this page |
| Full-text search | Type "export" or "MERMAID" in the search box at the top |
| Math, diagrams and code | [Markdown syntax](guide/markdown-syntax.md) |
| Custom sidebar order | Defined in `_sidebar.md` in this folder |
| Downloading an attachment | [Sample data (CSV)](files/sample-data.csv) |

## Folder layout

```text
sample-docs/

├── images/              images
```
