mdfolio

Version 1.5.0

mdfolio turns Markdown documents into a website you can browse using any modern web browser. It needs no server, no installation and no network connection. Just open the HTML file.

Try it

Read the sample documentsTry an example of "Export as site": a collection of documents packaged into a single HTML file. It works on smartphones too. Open your own folderThe viewer itself. Choose Markdown files or a folder on your device and read them. Custom look sampleThe same sample with an mdfolio.css placed next to it, changing the colors and headings. DocumentationHow to use mdfolio, the specification, and the test records, shown by mdfolio itself.

Your documents stay with you

Documents you open using "Open your own folder" are processed entirely within your browser. They are never sent to this site or anywhere else (the page's security settings block all network access).

Use it on your device

  • Download mdfolio.html (about 4.2 MB) and double-click it. That one file is all you need.
  • To change the look, place mdfolio.css (example) in the same folder as the HTML file.
  • The sample documents are in the zip file of the latest release.
